# A-Python-text-to-speech-project.V.2.0
В первой версии было всего 5 языков
Планируется добавить еще около 7-10 
Появится изменения в голосе(можно выбрать мужской или женский)
Можно будет изменять тепм речи и тон голоса 
При поставлееных запятых будет небольшая пауза
Планируется добавить преобразование звука в текст
Используемые библиотеки 
• pyttsx3: полностью офлайн, не требует интернета, но качество ниже облачных решений
• gTTS: высокое качество, множество языков, но требует подключения к интернету
• Mozilla TTS: баланс между качеством и автономностью, можно дообучать под конкретные задачи
• Amazon Polly: профессиональное качество, но платное и требует облачной инфраструктуры
• Tacotron 2 + WaveGlow: высшее
качество, но требует серьезных вычислительных ресурсов
